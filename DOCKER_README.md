# Быстрый запуск проекта GreenStore с помощью Docker

Этот проект настроен для запуска одной командой благодаря Docker Compose.

## Предварительные требования
- Установленный Docker Desktop для macOS
- Установленный Docker Compose (входит в Docker Desktop)

## Запуск проекта

Откройте терминал в папке проекта и выполните:

```bash
docker-compose up --build
```

### Что произойдет:
1. Docker скачает образы MySQL 8.0 и Tomcat 10.1 (если их нет локально).
2. Соберет WAR-файл вашего приложения с помощью Maven внутри контейнера.
3. Запустит базу данных и автоматически импортирует данные из `database/init.sql`.
4. Запустит Tomcat с вашим приложением.
5. Приложение будет доступно по адресу: **http://localhost:8080/greenstore**

## Остановка проекта

```bash
docker-compose down
```

Для полного удаления данных базы данных (сброс состояния):
```bash
docker-compose down -v
```

## Тестовые данные для входа

После запуска вы можете войти в систему используя следующие данные (из `init.sql`):

- **Логин:** `user@example.com`
- **Пароль:** `password123`

Или зарегистрировать нового пользователя через интерфейс.

## Примечания

- При первом запуске сборка может занять несколько минут (загрузка образов и зависимостей Maven).
- База данных хранится в Docker volume `db_data`, поэтому данные сохраняются между перезапусками.
- Если вы изменили код Java, просто выполните `docker-compose up --build` снова, чтобы пересобрать приложение.
- Если вы изменили только `database/init.sql`, используйте `docker-compose down -v` перед повторным запуском, чтобы сбросить базу данных.

## Доступ к логам

Чтобы видеть логи приложения в реальном времени:
```bash
docker-compose logs -f app
```

Логи базы данных:
```bash
docker-compose logs -f db
```
