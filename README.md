# Интернет-магазин - Веб-приложение на Java

## Описание проекта

Веб-приложение интернет-магазина на Java с использованием базы данных MySQL и архитектуры MVC.

## Технологии

- Java 11
- MySQL 8.0
- Maven
- Servlet API 4.0
- JSP
- JSTL
- Apache Tomcat
- BCrypt (для безопасного хэширования паролей)

## Установка и запуск

### 1. Настройка базы данных

1. Убедитесь, что MySQL запущен
2. Выполните SQL скрипт из файла `database/init.sql`:

```bash
mysql -u root -p < database/init.sql
```

Или выполните команды вручную в MySQL клиенте.

### 2. Настройка подключения к БД

Откройте файл `src/main/java/com/example/dao/DBConnection.java` и измените параметры подключения при необходимости:

```java
private static final String URL = "jdbc:mysql://localhost:3306/online_shop";
private static final String USER = "root";
private static final String PASSWORD = "password";
```

### 3. Сборка проекта

Выполните команду в корневой директории проекта:

```bash
mvn clean package
```

Это создаст WAR файл в директории `target/online-shop.war`

### 4. Развертывание на Tomcat

1. Скопируйте файл `target/online-shop.war` в директорию `webapps` вашего Apache Tomcat
2. Запустите Tomcat
3. Откройте браузер и перейдите по адресу: `http://localhost:8080/online-shop`

### 5. Альтернативный способ запуска (через Maven Tomcat плагин)

Добавьте в `pom.xml` плагин Tomcat (если еще не добавлен) и запустите:

```bash
mvn tomcat7:run
```

- Просмотр истории заказов

## Тестовые данные

В файле `database/init.sql` уже включены тестовые данные:
- 4 категории товаров
- 6 товаров в разных категориях

## Структура базы данных

- `users` - пользователи
- `categories` - категории товаров
- `products` - товары
- `cart` - корзина пользователя
- `orders` - заказы
- `order_items` - элементы заказа

## Важные замечания

1. Убедитесь, что MySQL запущен перед запуском приложения
2. Проверьте параметры подключения к БД в `DBConnection.java`
3. При первом запуске убедитесь, что база данных инициализирована
4. Для продакшена рекомендуется использовать пул соединений вместо прямого подключения

## Безопасность

- **Пароли хэшируются** с использованием BCrypt перед сохранением в базу данных
- Пароли никогда не хранятся в открытом виде
- При проверке пароля используется безопасное сравнение хэшей
- Для продакшена рекомендуется добавить:
  - HTTPS для защиты данных при передаче
  - Защиту от SQL-инъекций (уже реализовано через PreparedStatement)
  - Валидацию входных данных
  - Защиту от CSRF атак
  - Ограничение попыток входа
